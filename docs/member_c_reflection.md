### Individual Reflection

Since this is my first time designing functional tests from scratch, I found it more challenging than I expected. There are many things that I need to consider, such as handling missing and 
invalid values in the rental dataset and ensuring the accuracy of rental price per square foot and grouped median calculations. Through this process, I gained a better understanding of how 
functional testing helps detect defects and improve software reliability.

Using an AI coding agent to generate parts of my code and monitor the changes it made was also a new challenge for me. I learned that I still need to review and fix the code after the AI agent 
finishes its work. For example, the AI agent may change certain constraints or boundary conditions to make the code run successfully without actually solving the original problem correctly. 
This experience made me realize that passing all tests does not necessarily mean the code is correct. I still need to understand the logic behind the code and make sure it meets our original 
project requirements rather than relying entirely on AI-generated solutions.
